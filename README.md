# 实学夜话

**校园音频与「一封家书」微信小程序。**

让学校的声音被认真听见，让家庭与学校之间的表达更真诚、更有仪式感。

## 产品介绍

实学夜话面向学生、家长和教师：校长或指定管理员发布校园音频，用户随时收听、收藏和续播；学生、家长和教师以文字与图片写下家书，由管理员审核后精选展示。首期服务单所学校，数据结构预留多校能力，按个人主体、非商业项目规划。

核心流程：**微信登录 → 选择身份与班级 → 收听夜话 / 撰写家书 → 管理员审核 → 精选展示**。

| 使用者        | 产品提供的价值                                 |
| ------------- | ---------------------------------------------- |
| 学生          | 收听校园故事、记录成长和表达感谢               |
| 家长          | 利用碎片时间了解学校理念，以家书参与家校表达   |
| 教师          | 收听与投稿，自选教师身份不自动获得管理权限     |
| 校长 / 管理员 | 在小程序内发布音频、审核家书、维护本校内容     |
| 超级管理员    | 初始化学校、授予和撤销管理员权限、维护全局配置 |

详见[产品概览](docs/PRODUCT.md)与[产品需求文档](docs/PRD.md)。

### 在 Mac 上运行

在仓库根目录执行（推荐使用 `.nvmrc` 指定的 Node 24 LTS）：

```bash
npm ci
npm --prefix miniprogram ci
npm run build
npm run devtools:build-npm
npm run devtools:open
```

微信开发者工具打开的是整个仓库根目录，`miniprogramRoot` 已指向 `miniprogram/`。点击启动页的“进入页面预览”即可查看界面。当前无需填写云环境，也不用重新创建项目。

质量检查：`npm run verify`。当前本地验收入口：`npm run verify:stage2`，串联质量检查、格式检查、实际云包验证、两个数据库 dry-run、生产依赖审计和阶段 2 模拟器检查；各子命令已分别实际运行通过，未记录整条串联命令一次退出 0。该入口需要可连接的微信开发者工具，不会执行云部署或数据库 `--apply`。详细要求见[开发指引](docs/DEVELOPMENT.md)。

## 功能规划

| 模块       | V0.1 交付范围                                             | 对应任务                          |
| ---------- | --------------------------------------------------------- | --------------------------------- |
| 登录与班级 | 微信登录、身份选择、学校 / 年级 / 班级选择和切换          | TASK-103、200～202                |

| 音频管理   | 管理员上传、草稿、预览、发布、下架、软删除                | TASK-304～305                     |

| 管理中心   | 家书审核、班级管理、管理员授权、功能开关、日志、通知      | TASK-404、500～504                |

## 技术栈

| 层次       | 方案                                                                           |
| ---------- | ------------------------------------------------------------------------------ |
| 小程序     | 微信原生、TypeScript strict、WXML、WXSS                                        |
| 组件与状态 | TDesign Miniprogram；用户与播放器采用统一 Store，按任务书使用 MobX Miniprogram |
| 后端       | CloudBase 云函数、文档数据库、云存储、安全规则与日志                           |
| 调用分层   | 页面 → service → 领域云函数 → 数据库 / 存储                                    |
| 质量工具   | ESLint、Prettier、TypeScript strict、Vitest；精确版本与锁文件已建立            |
| 权限       | 服务端取得可信 OpenID，校验角色、授权学校与资源范围；业务记录软删除            |

版本、云函数打包、环境边界及官方来源见[技术栈与架构](docs/TECH_STACK.md)。
