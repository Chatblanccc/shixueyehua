# 实学夜话

校园音频与「一封家书」微信小程序。

让学校的声音被认真听见，让家庭与学校之间的表达更真诚、更有仪式感。

## 当前状态

本仓库目前处于 **V0.1 开发基线文档阶段**，已收录产品需求、Codex 开发任务书及开发规则。尚未包含小程序源码、云函数、依赖配置或可执行测试，也尚未完成部署与真机验收。下述功能与技术栈均为开发规划。

## 产品定位

实学夜话面向学生、家长和教师，以校长或指定管理员发布的校园音频为核心，以经过审核的「一封家书」承载家校表达。首期围绕单所学校试点，数据结构预留多学校能力，按个人主体、非商业项目设计。

### V0.1 规划功能

| 模块 | 计划能力 |
| --- | --- |
| 登录与班级 | 微信登录，选择学生、家长或教师身份，选择和切换学校、年级、班级 |
| 夜话电台 | 音频列表与详情、播放控制、后台播放、进度续播、历史与收藏 |
| 一封家书 | 文字与最多 3 张图片投稿、草稿、提交审核、查看状态、撤回与举报 |
| 小程序管理中心 | 管理员上传和发布音频、审核家书、管理班级；超级管理员授权管理员 |
| 安全与运营 | 服务端权限与学校范围校验、内容安全、功能开关、操作日志 |

用户主流程：登录 → 选择身份与班级 → 收听夜话 / 投稿家书 → 管理员审核 → 精选展示。

### 产品边界

- 只有管理员与超级管理员可以上传、发布音频。
- 普通用户可以投稿文字和图片，家书公开展示前必须审核。
- 用户身份与系统权限分离，自选教师身份不会获得管理员权限。
- V0.1 不提供评论、私信、关注、排行榜、支付、广告、普通用户音频上传或独立 Web 管理后台。

## 计划技术栈

- **前端：**微信原生小程序、TypeScript 严格模式、TDesign Miniprogram。
- **后端：**微信云开发 CloudBase 云函数、文档数据库、云存储与安全规则。
- **调用分层：**页面 → 服务层 → 云函数 → 数据集合。
- **权限原则：**所有特权写入经云函数校验角色与学校范围，不信任客户端传入的 OpenID、角色或审核状态；业务记录采用软删除。

## 开始参与开发

```bash
git clone https://github.com/Chatblanccc/shixueyehua.git
cd shixueyehua
```

1. 先阅读开发规则、产品需求文档和开发任务书。
2. 从任务书中的 `TASK-000` 仓库审计开始，再按依赖推进工程初始化与业务开发。
3. 每次交付记录任务编号、修改文件、验证结果及已知限制。
4. 工程初始化后运行 lint、类型检查和测试，并补充真实的安装、构建与运行命令。

当前没有 `package.json` 或微信开发者工具项目配置，不能直接安装依赖或运行小程序。云环境配置、部署步骤与真机验收记录将在对应任务完成后补充。请勿提交真实密钥、凭据或用户隐私数据。

## 验收目标

V0.1 的最终目标是跑通「登录选班 → 收听夜话 → 保存进度 → 投稿家书 → 管理员审核 → 精选展示」，并完成权限隔离、内容安全、自动化检查以及 iOS / Android 真机验证。具体标准以产品需求文档与开发任务书为准。
