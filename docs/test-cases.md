### 跳转修复与频繁重启的原因

管理页守卫此前会在进入页面的路由动画结束前发起 `reLaunch`，导致页面画面与引擎栈不一致。现在由 `onBeforeAppRoute` / `onAppRouteDone` 跟踪动画完成，再按队列执行跳转；相同目标会合并。基础库 3.17.3 的 `reLaunch` 完成事件没有 routeEventId，因此只在路径、路由类型与原生页面 ID 唯一匹配时完成对应等待，遇到歧义或超时不会强行放行。

验收脚本本身会重新启动小程序、切换页面，并主动测试七次管理页拦截；开发者工具也会对源文件变化自动编译。这些操作会让界面反复回到启动页。本轮已将生成脚本改为内容相同不写文件，并验证修改时间不变；当前验收脚本已结束。通过日志未记录未捕获异常，但这不能证明所有设备上都不会发生崩溃。
