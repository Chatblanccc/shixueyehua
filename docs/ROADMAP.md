## 1. 当前状态与“第一阶段”的含义

仓库克隆和 TASK-000 已完成，**阶段 1 本地验收全部通过，尚未进入阶段 2**。Node `24.21.0` 下的完整质量检查、13 文件 / 124 项测试、格式检查、六个实际云包的仓库外安装 / 加载 / 审计均通过；模拟器启动、四 Tab、七管理页共 12 项检查通过，异常为 0。持续状态见[实施计划](implementation-plan.md)、[测试记录](test-cases.md)和[独立验收复核](acceptance-review.md)。

**第一阶段严格指原阶段 1“共享基础、数据与鉴权”，包含 TASK-100、TASK-101、TASK-102、TASK-103。** 阶段 0 的 TASK-001～003 是其工程前置。用户已说明暂无正式 AppID，选择先完成本地开发；当前测试号不能使用云服务，因此本地成果与尚未完成的云端验收分开记录。

云函数未部署，真实数据库 / 规则 / 超管授权和手机验收未执行。已通过的模拟器检查仅证明本地页面与守卫导航；真实微信身份与云端权限仍须另验。身份选班、音频和家书业务仍在后续阶段。

第一阶段结束时，应具备共享类型与接口、统一云函数内核、可重复执行的数据库初始化和可信登录会话。选身份选班、音频收听和家书审核分别属于后续阶段，不能用第一阶段验收替代完整产品验收。

## 2. P0、P1 与版本范围

- **P0**：核心闭环、基础依赖及安全发布保障，优先实现并逐项验收。
- **P1**：任务书中安排在核心能力之后的功能优先级，不自动等于移出 V0.1。
- **V0.1 必交付**：由 PRD 的版本范围决定。举报 TASK-405、班级管理 TASK-501、日志与通知 TASK-504 虽标 P1，仍需对照 PRD 的交付要求完成；如要缩减版本范围，必须先明确修订需求，不能仅因 P1 标签省略。
- 共享审计能力 TASK-101、各管理动作写日志、TASK-404 审核结果通知写入已有 P0 要求，不能等到 TASK-504 的查询与展示功能才补。
- 发布时不得存在未处理的 P0/P1 安全缺陷。

### 第一阶段退出条件

1. TASK-100～103 各自交付与对应文档齐备，`npm run lint`、`npm run typecheck`、`npm test` 真实通过。
2. 在隔离的开发 CloudBase 环境验证初始化、索引、登录幂等与共享内核，记录运行环境和结果；mock 测试单列，不能替代云端验证。
3. 数据库从初始化起默认拒绝未经授权的客户端写入，不能为登录调试开放角色或配置写权限。
4. 下一阶段所需的身份完善与选班路由边界明确；尚未实现的页面不返回固定数据冒充业务成功。
5. 更新 [实施计划](implementation-plan.md) 的每项状态、修改文件、检查结果及已知限制。没有真实环境结果时保留未验证状态。

## 7. 必须提前落实的安全依赖

### TASK-600：家书提交前可用

在 TASK-101 共享内核之后实现内容安全适配层，并在 TASK-400 家书真实提交联调前完成接入。文本、图片的通过、复核、拒绝及超时处理均要有测试；正式调用不能沿用测试 mock。家书被允许公开前，必须完成内容安全检查和管理员审核。

### TASK-601：数据与文件接入即设边界

任务书将 TASK-601 的完整验收依赖列为 TASK-102、TASK-304、TASK-401，因为最终规则需匹配数据库和两类上传路径。执行时分步落实：

1. TASK-102 创建集合时，先落实默认拒绝和受保护字段禁止客户端写入。
2. TASK-304 的音频上传真实联调前，落实管理员上传授权、学校目录、临时文件归属及确认规则。
3. TASK-401 的图片上传真实联调前，落实作者目录、文件类型/数量限制及他人文件保护。
4. 路径与流程齐备后，按 TASK-601 集中回归客户端直接提权、跨用户文件删除、覆盖正式音频等攻击场景，取得完整验收证据。

以上提前实施仍归属 TASK-601；局部规则通过不等于整个任务已完成。不得为联调临时开放全库读写或无归属限制的上传目录。

## 8. V0.1 发布关口

- **业务闭环**：登录选班、管理员发布、收听续播、投稿审核、精选展示，以及 PRD 约定的举报和管理能力有真实证据。
- **权限与数据**：普通用户不能上传发布音频，客户端不能提权，学校范围隔离，家书状态机和软删除有效。
- **质量与体验**：质量命令通过，弱网、后台、重复操作及上传中断可恢复；测试不依赖正式数据。
- **设备验证**：iOS 与 Android 分别验证登录、播放/后台播放、上传、图片及审核，记录机型与微信版本。
- **发布准备**：配置、隐私说明、管理员与学校数据、备份、孤立文件清理及已知问题核对完成；按发布时的官方要求另行完成平台提审。
- **依赖安全**：本轮根生产依赖、实际函数运行包和小程序审计均为 0；根全量依赖剩余 17 项 moderate，high / critical 为 0。按[依赖审计](dependency-audit.md)处理剩余开发工具告警，并在真实部署前重新审计和回归；审计为 0 不替代云端安全验收。

代码可构建、云端可运行、真机验收通过和平台批准是不同状态，逐项记录。具体开发操作见 [仓库首页](../README.md) 的开发指引导航。
