# 阶段 1 数据库与存储规则

对应 TASK-102 与 DEC-003。**规则文件及部署 / 回读代码已实现，尚未部署到真实开发环境。**

## 1. 初始规则

[数据库规则](../database/rules/database.rules.json) 与[存储规则](../database/rules/storage.rules.json) 均为：

```json
{
  "read": false,
  "write": false
}
```

对 manifest 中 13 个数据库集合分别应用；存储规则覆盖目标开发环境的云存储。普通客户端、已登录用户以及在 `users` 中标为 admin 的客户端均不能直接读写。这里的 CloudBase 服务端管理员权限与产品的 `users.role` 不同：受控 SDK / 云函数服务端仍可访问，必须由每个业务云函数自行鉴权、校验学校范围并记录审计。

因此客户端不能直接修改 `role` / `adminSchoolId`、音频发布状态、家书审核状态、日志、配置，也不能直接读取他人私有家书。选班或自填角色不会改变规则。

## 2. 部署与故障

遵循[数据库初始化命令](database.md#4-真实初始化)。脚本在种子写入前设置并回读规则；若无权限、返回值异常或规则未达到完全拒绝，初始化失败。没有控制台“已部署”的模拟结果，不自动降级为 READONLY / PRIVATE，也不从客户端补写数据。

可在 CloudBase 控制台手动核对每个集合“权限设置 / 安全规则”及“云存储 / 权限设置”的实际内容；需要人工补部署时使用本仓库两份规则的同一内容，保存后再次回读并验证。该核对不替代真实客户端访问测试。存储规则变更可能异步传播，回读配置正确不代表旧临时链接已失效；阶段 1 不生成可公开访问的音频 / 图片链接。

## 3. 真实开发环境验收

使用专用开发环境中的虚构记录执行，记录时间、工具版本、实际环境和平台返回的 requestId / 错误码，不在证据中保存真实 OpenID 或家庭内容。

| 场景                                                | 应有结果                         |
| --------------------------------------------------- | -------------------------------- |
| 未登录客户端读 `users`、`letters`、`system_configs` | 拒绝                             |
| 普通用户直接读取其他用户记录和未审核家书            | 拒绝                             |
| 普通用户直接修改自己的 role/adminSchoolId           | 拒绝                             |
| admin 客户端直接修改任意集合                        | 拒绝；管理操作必须走云函数       |
| 客户端直接修改审核 / 发布状态、写日志和配置         | 拒绝                             |
| 未授权客户端上传、下载、删除云文件                  | 拒绝                             |
| 通过可信云函数首次登录创建默认 user                 | 成功；身份来自微信上下文         |
| 再次 / 并发登录同一真实账号                         | 只有一个用户记录                 |
| 服务端测试插入相同 openid / 收藏键 / 播放进度键     | 唯一索引拒绝第二条               |
| 连续两次初始化                                      | 第二次新增集合、索引和种子均为 0 |
| 不存在用户、非 dev 环境执行超管授权                 | 拒绝且不造用户                   |

后续上传开发需按 TASK-601 明确类型、大小、归属、临时文件绑定、服务端校验和清理；内容安全 TASK-600 必须先于真实家书提交流程。不能为了出现“上传成功”提示而开放全体写入或公开私有文件。

## 4. 本地证据边界

本地测试校验规则文件与实际部署常量一致，且 SDK 返回允许读取 / 写入、非法结构或错误码时失败。事务测试覆盖回滚与并发编排；它们均使用可控适配器，不能证明真实数据库权限、真实微信身份、索引建立或云存储拒绝已验证。TASK-102 的真实验收在有权限的正式小程序开发环境连通后进行。
