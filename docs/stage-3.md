## 已完成的任务

| TASK | 实现                                                                                                                                                                                                                                           |
| ---- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 300  | `audioApi.list/detail` 只从可信用户的当前学校、班级读取已发布且未删除的内容；游标绑定查询范围和快照，详情重新验证可见性。列表合并个人进度和收藏，媒体仅在请求详情播放 URL 时签发短期临时地址。                                                 |

## 本地验证

```bash
npm run verify
npm run format:check
npm run check:cloud
```

2026-09-16 提交前复核：上述命令均退出 0，26 个测试文件、325 项测试通过；数据库与首次管理员初始化 dry-run、根目录与小程序生产依赖审计、`git diff --check` 也通过。用例覆盖跨校/跨班与草稿/下架隔离、游标稳定性、详情 URL、进度限流与完成状态、收藏幂等、播放器迟到事件/切集/断网/过期 URL、存储路径和实际媒体字节校验，以及本地模式隔离、持久化与上传失败处理。`check:cloud` 在仓库外按云函数运行包安装后加载六个入口并完成生产依赖审计；它不调用真实云 API。
